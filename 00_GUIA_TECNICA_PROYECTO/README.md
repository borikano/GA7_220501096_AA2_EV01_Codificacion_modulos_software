# Guía técnica del proyecto EV01

Repositorio: GA7_220501096_AA2_EV01_Codificacion_modulos_software.

Esta guía facilita la lectura, ejecución, prueba y auditoría técnica de la evidencia EV01 de codificación de módulos de software.

## Objetivo

Documentar un módulo de software en Java para la gestión CRUD de usuarios usando conexión JDBC con MySQL.

## Rutas principales

| Ruta | Propósito |
|---|---|
| src | Código fuente Java del proyecto. |
| docs | Documentación técnica y evidencia funcional. |
| evidencias/EV01-CRUD-CONSOLA | Punto de entrada para evidencias funcionales de la EV01. |
| README.md | Presentación principal del repositorio. |
| 00_GUIA_TECNICA_PROYECTO | Guía técnica pública de navegación. |

## Documentación recomendada

- docs/EVIDENCIA_FUNCIONAL.md
- README.md

## Código fuente

El código fuente principal se encuentra en la carpeta `src`.

## Base de datos

El proyecto usa conexión JDBC con MySQL. La estructura de base de datos fue versionada mediante script SQL en el historial del repositorio.
